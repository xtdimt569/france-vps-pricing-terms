## 同在巴黎，0.51ms 和 23.98ms 差在哪

EDIS 在产品页公布了巴黎机房的测速记录：机房位于 EQUINIX PA2（St. Denis，GPS 48.928, 2.352），2026 年 9 月 27 日从 kvm-lps-fr08 用 Ookla Speedtest CLI 测到巴黎 KEYYO，下载 8,059.87 Mbps、上传 3,085.87 Mbps、空闲延迟 0.51 ms，Ookla 识别到的运营商是 M247 Europe。同一页还有一个对比结果：测到巴黎 Scaleway 是 14,695.41 Mbps 下载、1,533.5 Mbps 上传、23.98 ms 延迟。

同一台机器、同一个城市，两个测速目标，延迟差 47 倍，下载速度反过来差近一倍。这说明“巴黎机房延迟 0.5 ms”这种说法本身没有意义，有意义的是“到你的目标用户或上游的延迟”。页面自己附了一句声明：这只是该时点对特定测速服务器的单次测量，不构成对其他目的地吞吐或延迟的保证。做选型时，比看宣传数字更靠谱的做法是用机房提供的 Looking Glass 从自己网络跑一遍 ping 和 traceroute。EDIS 在巴黎页面上就提供了这个入口。

Evoxt 拿出来的差异点不在网络侧，在 CPU 频率。它标称最高 6.0 GHz 加速频率，第三方评测称 VPSBenchmarks 的独立测试能对上这个数字，而多数低价 VPS 的服务器 CPU 跑在 2.2–2.5 GHz。对单线程敏感的任务（WordPress 的 PHP 执行、Discord bot、编译、单连接 API），这个差距比多给一个核更明显；反过来，跑大量并发短连接或做视频转码，核数和端口带宽才是瓶颈。

## 要法国 IP、多站点、做 SEO 的人看这段

OVHcloud 在自家 FAQ 里把服务器位置和 IP 地理定位直接跟 Google 排名挂钩，说本地用户更愿意点击本地站点，并支持低价加购地理定位 IP，单台最多 16 个附加 IP，覆盖 13 个欧洲地理定位。EDIS 的附加 IPv4 是 €5/月一个，最多 10 个，支持 rDNS（反向 PTR）委派，做 VPN 出口和多服务托管时这条比多一个核有用。IWIHOST 强调每台含独立 IPv4、不与邻居共享，避免被别人的流量拖进黑名单。Evoxt 的控制台提供 IP 管理与 Floating IP 下单入口，官方页面没有列出单价。

做站群、邮件投递或 VPN 分销，值得先问清三件事：能不能加 IP、IP 注册地在哪、能不能改 rDNS。这三项决定后续能不能扩展，CPU 型号反而次要。

## 常见问题

**法国机房对法国用户的延迟大概什么水平？**
同城测速服务器可以低到 1 ms 以内，EDIS 公布的 0.51 ms 就是这种口径。跨城或跨运营商通常在 5–25 ms。真实数字取决于你的用户接的是哪家运营商，用 Looking Glass 从自己的网络测才有意义。

**能不能加 IP？**
OVHcloud 最多 16 个附加 IP，EDIS 每个 €5/月、最多 10 个并支持 rDNS，IWIHOST 每台含独立 IPv4。Evoxt 控制台有 IP 管理和 Floating IP 入口，价格在结账页确认。

**能不能退款？**
Infrawire 明确 7 天退款、无合约束缚。EDIS 走年付送一个月的路子。Evoxt 的退款条款没有出现在抓取到的产品页上，下单前用结账页条款或工单确认，别默认有。

**能不能跑 Docker？**
表里这几家都标称 KVM 全虚拟化，可自带内核、改 iptables、嵌套跑 Docker 和 LXC。容器型伪 VPS（多用户共享内核）做不到这些，下单前看清虚拟化类型。

**能不能装 Windows？**
EDIS 覆盖到 Windows Server 2025 与 Windows 11，OVHcloud 支持一键部署，IWIHOST 只在中高配提供。装 Windows 前先确认内存是否够，2 GB 跑 Windows Server 会很难受。

## 下单前的最后几条规则

只要一台小机器跑轻量服务，VM-0.5 或 VM-0.75 就够，多花的钱买不到体感差异。要跑 WordPress、API 或两三个站，VM-1 的 2 GB / 20 GB 是这条产品线上性价比最集中的一档。要上数据库、容器或多站点，直接看 VM-2 和 VM-3，别在 2 GB 上硬撑。
